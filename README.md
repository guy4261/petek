# פתק

עמוד סטטי בעברית, ללא התקנות או תלויות. פתחו את index.html בדפדפן.

- לחצו על האותיות כדי לערוך עד שלוש אותיות במקום.
- לחצו על המשפט שמתחת כדי לערוך אותו במקום.
- גררו את השטח הריק של הנייר סביב מרכזו לסיבוב חופשי.
- הכתובת מתעדכנת אוטומטית עם הפרמטרים `letters`, `text`, `angle`. העתקת הכתובת ופתיחתה משחזרת את הפתק. לשיתוף עם אחרים השתמשו בכתובת האתר ב־GitHub Pages.

## GitHub Pages

העלו את index.html לשורש המאגר. תחת Settings → Pages בחרו Deploy from a branch, את הענף main ואת / (root), ושמרו.
