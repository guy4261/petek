# פתק

עמוד סטטי בעברית, ללא התקנות או תלויות. פתחו את index.html בדפדפן.

- לחצו על האותיות כדי לערוך עד שלוש אותיות במקום.
- לחצו על המשפט שמתחת כדי לערוך אותו במקום.
- גררו את השטח הריק של הנייר סביב מרכזו לסיבוב חופשי.
- הסיבוב מתבצע בגרירה באצבע אחת או בעכבר בלבד. צביטה בשתי אצבעות משמשת לשינוי גודל הטקסט בלבד: מרכז המחווה בתחילתה קובע אם לשנות את הטקסט העליון (50% העליונים של המסך) או התחתון (50% התחתונים), גם מחוץ לפתק. גלילת עכבר משתמשת באותה חלוקה.
- הכתובת מתעדכנת אוטומטית עם הפרמטרים `letters`, `text`, `angle`. העתקת הכתובת ופתיחתה משחזרת את הפתק. לשיתוף עם אחרים השתמשו בכתובת האתר ב־GitHub Pages.

## גופן וגודל הטקסט

- האותיות העליונות והטקסט התחתון משתמשים בגופן `David`.
- גודל האותיות העליונות מוגבל לטווח `24px`–`110px`.
- גודל הטקסט התחתון מוגבל לטווח `12px`–`35px`.
- המגבלות חלות גם על התמונה המיוצאת. הטקסט עשוי להצטמצם כדי להישאר בתוך הפתק.
- הגופן נלקח מהמכשיר; אם `David` אינו מותקן, הדפדפן משתמש בגופן חלופי ממשפחת serif.

מקור לבחירת הגופן ולערכי הגבול: [משרד הפנים — פתקי הצבעה, חוזר מוא״ז 10, עמוד 2, הסעיף ״גודל האותיות והכינוי״](https://www.gov.il/BlobFolder/guide/election-2024-23/he/elections_2024_12_elections-15-12-24-2.pdf#page=2). המסמך מציין את גופן DAVID וגבולות הגודל 110 לאותיות ו־35 לכינוי. היישום באתר משתמש בערכים אלה בפיקסלים לצורכי תצוגה בדפדפן; המסמך אינו מציין יחידות פיקסלים.

## GitHub Pages

העלו את index.html לשורש המאגר. תחת Settings → Pages בחרו Deploy from a branch, את הענף main ואת / (root), ושמרו.
